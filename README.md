# My Portfolio

My personal portfolio, showcasing my projects and development skills. Built with HTML, CSS and JavaScript.

[View portfolio](https://thatmaybethecase.github.io/Portfolio/)

## Features

- Project gallery with repository links and demos
- Interactive skills section
- Interactive terminal with navigation commands, contact details and a virtual coffee
- Responsive layout with mobile navigation

## Design

A System24-inspired design with muted colours, flat panels and monospace typography.

## Run locally

Clone or download the repository and open `index.html` in your browser. No installation or build step is needed.
